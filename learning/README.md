# Learning: expanded stages

One file per Learning-Track stage, written when I reach it. `learning/Learning-Track.md` stays the map (stages, order, checkpoints). Each file here is the territory for one stage: the checkpoint expanded into what a passing answer sounds like, the material in order with time and where it fits (shift or home), the hands-on that fits a slow shift, and a self-test to say out loud, cold.

Rules are the same as the track: work first, checkpoint out loud, no calendar. A file here is a study plan, not a rep. The daily case file never waits on any of this.

To expand the next stage: `/expand-stage A2` (the saved procedure lives in `.claude/skills/expand-stage/`).
